# Export and QA / 导出与交付检查

| What the buyer needs / 使用目标 | Deliverable / 文件选择 |
| --- | --- |
| Finished product image / 发布成品 | PNG for sharp text or transparency. JPG when a smaller opaque image is needed or the destination asks for it. 细字、线条或透明底用 PNG；渠道要求或需要更小的实底图片时用 JPG。 |
| Editable vector artwork / 可编辑图稿 | SVG with editable text and embedded images. Supply font names when the receiver may not have them. 交付保留文字与内嵌图片的 SVG；对方可能缺少字体时说明字体。 |
| Reusable website template / 网站离线模板 | AD.FOLIO's downloaded HTML is opened in a browser. Use its save action to keep an editable copy. AD.FOLIO 的离线 HTML 用浏览器打开，在页面中保存新的可编辑副本。 |
| Multiple pages / 多页交付 | Keep editable source per page, then supply numbered image files and optionally a ZIP or a stitched long PNG. 每页保留可编辑源稿，成品按顺序编号；需要时附压缩包或拼接长图。 |
| Image in a spreadsheet / 表格里放图 | Open the workbook and insert the PNG or JPG as a picture. 先打开表格，再用「插入 → 图片」添加 PNG 或 JPG。 |

AD.FOLIO's preview uses a 1080 × 1440 frame for a Xiaohongshu card and a 1080 × 1080 frame for other listing mockups. These are design presets. Verify a named platform's current upload rules for the specific placement when the brief requires them. 网站的小红书卡片预览为 1080 × 1440，其他列表模拟为 1080 × 1080。这些是设计预设；如需符合特定平台的上传要求，请按具体入口核对。

## Product and file checks / 商品和文件检查

1. **Before layout / 排版前。** Identify the exact product and variant. If removing the background, check edges, transparent materials, and small details. Keep the original so a poor cutout does not block delivery.  
   确认商品与型号。抠图后检查边缘、透明材质和小细节，保留原图以备回退。
2. **Before export / 导出前。** Check the latest product image is visible and all fonts and images are ready. Embed assets in portable SVG files. Inspect the thumbnail and each target crop for cut-off text, price, product, and CTA.  
   确认最新商品图已进入画布，字体和图片加载完成。便携 SVG 应内嵌素材；检查缩略图和目标裁切有没有切掉文字、价格、商品或行动提示。
3. **After export / 导出后。** Reopen the actual file. Check dimensions, content, crop, transparency where expected, and whether the filename extension matches the format. In a multi-page set, verify the order and every page.  
   用实际导出的文件重新打开检查尺寸、内容、裁切、预期的透明效果和扩展名。套系逐页核对并检查顺序。
4. **Before delivery / 交付前。** Confirm prices, dates, offer terms, materials, and performance claims. Separate editable source from finished images and state which file to publish.  
   核对价格、日期、优惠条件、材质和功效。分清可编辑源稿与成品图，并说明哪一个文件用于发布。
