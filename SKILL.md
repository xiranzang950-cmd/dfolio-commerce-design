# AD.FOLIO Commerce Design / 有料电商平面设计

## Workflow / 工作流程

1. **Read the brief / 读懂需求。** Identify the product, buying decision, placement, language, required output, and which assets and claims are supplied. Ask only when a missing decision changes the deliverable. Mark unknown prices, offers, dates, and specifications as placeholders.  
   确认商品、购买决策、使用场景、语言、交付格式和已有素材。只有缺失信息会影响成品时才追问；未知价格、优惠、日期或规格请标为待确认。
2. **Choose the right canvas / 选对画布。** A main image identifies one product quickly. A poster sells one offer or launch. A detail page answers buying questions. A store banner introduces a collection. For a set, define the cover, highlights, close-up, use case, and specifications before styling. Read [layouts and styles](references/layouts-and-styles.md) for dimensions, style selection, and page order.  
   主图用来识别商品，海报突出一个活动，详情页回答购买疑问，店铺横幅引导选购。做五页套系时，先定封面、亮点、细节、场景和规格。
3. **Design with the actual product / 用真实商品做设计。** Use the supplied image and preserve its aspect ratio. Compare two viable directions when a style is unspecified and the choice affects the result. Keep the name or offer readable at thumbnail size, the product visually distinct, and the price or call to action in a clear secondary position.  
   优先用用户的商品图，保持比例。如果风格未定且会影响结果，比较两个合适方向。缩略图上也要认得出商品、读得清名称或活动主题，再看价格和行动提示。
4. **Deliver editable work / 交付可改的成品。** Match the requested format and language. Preserve text as editable text when possible, and use transparent assets where appropriate. The optional [local SVG starter](scripts/render-svg.mjs) makes a single-page editable file from a local JSON brief and optional PNG/JPG. Adapt its layout to the product, or build a custom design if the starter is too limiting. Read [export and QA](references/export-and-qa.md) before reporting completion.  
   按需要交付可编辑稿和成品图。可选用本地 SVG 脚本做单页初稿，再按实际商品调整；多页套系分别交付各页。

## Working conventions / 使用约定

- Match the user's language by default. For bilingual artwork, choose a primary reading language, give the other a clear secondary role, and check both independently.  
  默认用用户的语言。双语设计要确定主读语言，并分别核对两种文字的可读性。
- Design only with substantiated claims and permitted imagery. If no image is available, use a clearly identified sample or placeholder, without presenting it as the real product.  
  使用经确认的商品信息与有权使用的素材。无商品图时，明确注明示意图或占位图。
- For a style request or a tour of the website's designs, use the [bilingual catalog](references/catalog.md). It indexes the website's design directions. For a task on an existing website, follow the user's authorized scope for that site.  
  查找风格或了解网站模板时，可看双语目录。涉及现有网站的编辑或发布，以用户明确授权的范围为准。

The local workflow works with user-provided assets and does not require the hosted AD.FOLIO site. 本地流程可使用用户提供的素材，不需要登录 AD.FOLIO。
